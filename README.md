\# 🌿 AirAware AI

\### Breathe Better. Live Smarter.



AirAware AI is a GenAI-powered urban air quality assistant designed to help families and communities make safer daily decisions during winter smog and urban air pollution.



It combines live modeled air quality data, Gemini AI assistance, personalized health precautions, indoor air guidance, and sustainable commuting insights in one application.



\## ✨ Key Features



\### 1. Urban Air Quality Dashboard

\- Live modeled air quality data through Open-Meteo Air Quality API.

\- Indian National Air Quality Index (NAQI).

\- PM2.5, PM10, NO₂, O₃, SO₂, and CO breakdown.

\- Health implications and pollutant comparisons.

\- 24-hour modeled air quality trends.



\### 2. Gemini AI Assistant

\- AI-powered family air pollution protection plans.

\- Personalized recommendations based on location and household profile.

\- Practical advice for sensitive groups.

\- Health and safety guidance.



\### 3. Smart Daily Routine Planner

\- Personalized outdoor activity recommendations.

\- School-going children's precautions.

\- Elderly care guidance.

\- Low-emission commuting suggestions.



\### 4. Indoor Air Quality Guide

\- Smart ventilation recommendations.

\- Kitchen exhaust and cooking emission guidance.

\- Indoor smoke prevention.

\- HEPA air purifier information and CADR estimator.



\### 5. Home Clean-Air Audit

\- Interactive six-point household checklist.

\- Progress tracking for indoor air protection practices.



\### 6. Eco Impact Tracker

\- Compare different commuting modes.

\- Estimate annual CO₂e savings.

\- Estimate PM2.5 and NOx reductions.

\- Interactive emissions comparison charts.



\### 7. Household Personalization

\- Save household preferences.

\- Personalize recommendations according to family size and vulnerable household members.

\## 🚀 Run Locally



\### Prerequisites

\- Node.js

\- npm

\- Gemini API key



\### Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/Bhumiii-deval/AirAware-AI.git

&#x20;  ```



2\. Open the project directory:



&#x20;  ```bash

&#x20;  cd AirAware-AI

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install --legacy-peer-deps

&#x20;  ```



4\. Create a `.env` file in the project root directory.



5\. Add your Gemini API key:



&#x20;  ```env

&#x20;  GEMINI\_API\_KEY=YOUR\_GEMINI\_API\_KEY

&#x20;  ```



6\. Start the development server:



&#x20;  ```bash

&#x20;  npm run dev

&#x20;  ```



7\. Open the local URL displayed in your terminal.

\## 🔐 API Key Security



\- Keep API keys private.

\- Never commit your `.env` file.

\- Configure your Gemini API key through environment variables or the deployment platform's secret manager.

\- Do not expose private API keys in frontend code.



\## ⚠️ Important Data Disclaimer



\- Air quality readings are modeled estimates from the Open-Meteo Air Quality API, not direct measurements from a local monitoring station.

\- Observations may have a reporting delay.

\- Forecasts are estimates and are not guaranteed.

\- Always check the latest local air quality before outdoor activities.

\- AI-generated recommendations are informational and are not a substitute for professional medical advice.



\## 🌱 Project Goal



AirAware AI aims to make air quality information easier to understand and turn it into practical everyday actions for healthier households and cleaner communities.
